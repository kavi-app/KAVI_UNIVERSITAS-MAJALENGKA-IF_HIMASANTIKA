## Persyaratan

Sebelum menjalankan project, pastikan perangkat sudah terpasang:

* Node.js
* npm

Untuk memastikan Node.js dan npm sudah terpasang, jalankan:

```bash
node -v
npm -v
```

## Cara Instalasi

1. **Clone repository**

   Clone project dari repository berikut:

   ```bash
   git clone https://github.com/kavi-app/company-profile-lomba-1.git
   ```

2. **Masuk ke folder project**

   Setelah repository berhasil di-clone, masuk ke folder project:

   ```bash
   cd company-profile-lomba-1
   ```

3. **Install dependencies**

   Jalankan perintah berikut untuk menginstal seluruh dependencies yang dibutuhkan:

   ```bash
   npm install
   ```

## Cara Menjalankan Project

Setelah dependencies berhasil di-install, jalankan project menggunakan Node.js dengan perintah:

```bash
npm run dev
```

Setelah project berhasil dijalankan, terminal akan menampilkan alamat lokal seperti:

```text
http://localhost:5173
```

Buka alamat tersebut menggunakan browser untuk melihat landing page.

## Build untuk Production

Untuk membuat versi production, jalankan:

```bash
npm run build
```

Kemudian untuk melakukan preview hasil build:

```bash
npm run preview
```
