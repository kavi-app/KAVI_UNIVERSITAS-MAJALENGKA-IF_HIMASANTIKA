# Teknologi :

# Library :
- Lenis
- Lucide-react

# Cara Instalansi :
- Clone project dari repository https://github.com/kavi-app/company-profile-lomba-1.git
- Masuk ke folder project lalu pada folder project masuk ke terminal dan jalankan perintah npm install
- Jika install selesai jalankan project dengan perintah npm run dev
